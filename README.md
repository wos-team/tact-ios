# TACT iOS

TACTの締切が近い未提出の課題・小テストを、iPhoneの課題一覧とホーム画面ウィジェットで確認する試作です。

- 本人がアプリ内のTACT画面でサインインします。有効なTACTセッションを端末のKeychainで再利用します。
- ウィジェットは小サイズで1件、中サイズで最大3件を表示します。アプリを初めて開いた日の23:59まで約10分ごと、翌日からは約1時間ごとにTACTへの自動同期を試みます。実行時刻はWidgetKitが決めます。取得はiOSのバックグラウンド転送に任せ、完了時にホーム画面の表示を更新します。
- 同期に失敗しても前回の課題と最終同期時刻を表示します。再接続時は同じWebViewのデータストアを使います。
- 認証情報と課題データは端末に保存し、独自のサーバーを経由せずTACTに接続します。

## 起動

1. `TACT.xcodeproj` をXcodeで開きます。プロジェクトを再生成する場合は、XcodeGenを用意して `xcodegen generate` を実行します。
2. `TACT` と `TACTWidget` の両ターゲットで同じ署名チームを選びます。両ターゲットに App Group `group.jp.matsuokakoki.tact-ios` を割り当てます。別のグループを使う場合は `project.yml` のグループ設定と `TACTStore.group` を揃え、プロジェクトを再生成してください。
3. iOS 17以降のiPhoneで `TACT` スキームを実行し、「TACTに接続」を開きます。
4. iPhoneのホーム画面に「TACTの課題・小テスト」ウィジェットを追加します。

## 実機で確認すること

- 初回のTHERSログインから課題取得まで完了する。
- アプリを終了して開き直しても、有効なセッションで同期できる。
- 下書きや受験途中の小テストは残り、TACTで提出したものは同期後に消える。
- 課題は提出日時か提出済みフラグで判定する。小テストは講義の小テスト画面の「提出済みテスト」欄を読み取り、取得できたIDまたは講義内で一意のタイトルで照合する。提出状態の取得に失敗したときは講義を一部同期として表示する。
- 初回起動日に、ホーム画面のウィジェットをタップせず、「同期 ○分前」が新しくなるかを確認する。あとからアプリの「ウィジェットの自動同期」で実行時刻と結果を確認できる。既存端末では、この機能を含む版を最初に開いた日が対象になる。
- 翌日からは同期間隔が約1時間に戻る。TACTの期限切れ後も最後の課題が表示され、アプリで再接続できる。
- 期限切れ後の再接続で、パスワード再入力やMFAが必要になった回数を記録する。
